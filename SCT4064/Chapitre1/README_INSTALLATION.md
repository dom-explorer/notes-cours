## Publication GitHub Pages

Copier le dossier `SCT4064/Chapitre1/` à la racine du dépôt `dom-explorer/notes-cours`, en conservant les cinq pages HTML et leurs noms.

- Accueil du chapitre : `https://dom-explorer.github.io/notes-cours/SCT4064/Chapitre1/`
- Section 1.1 : `.../1_1_empreinte_ecologique.html`
- Section 1.2 : `.../1_2_ecotoxicologie.html`
- Section 1.3 : `.../1_3_traitement_eaux_usees.html`
- Section 1.4 : `.../1_4_biodegradation_polluants.html`

Chaque HTML embarque son propre CSS et JavaScript, sans dépendance vers `/styles.css` (qui appartient à `learnwithdom.page`). Les polices Google sont facultatives (polices de secours prévues).

## Images sous licence CC0

Les photographies proviennent de Wikimedia Commons. Leur licence CC0 1.0 a été vérifiée, et les liens vers les fiches avec le nom de l'auteur figurent dans chaque légende. Les fichiers images **ne sont pas inclus** : les `<img>` chargent les images directement depuis Wikimedia Commons et nécessitent une connexion Internet. Les éléments de la page, les calculs et les simulations restent utilisables sans ces images.

## Simulations

Les valeurs sont fictives et pédagogiques, pas des mesures, ni des normes de qualité de l'environnement, ni un diagnostic de contamination. Les pages sont indépendantes. Aucun prélèvement réel contaminé n'est requis ou conseillé.
