MAT-2101-3

Modélisation algébrique

L’algèbre est une manière de décrire des relations entre des quantités : donner un nom à ce qu’on cherche, construire un modèle, le vérifier, puis comprendre ce qu’il permet de prévoir. Cette collection permet de découvrir progressivement les expressions algébriques, les équations, les régularités, les rapports, les taux et les proportions.
