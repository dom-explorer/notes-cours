MAT1102-3 · Collecte, organisation et interprétation de données / L'étude statistique

La population, l'échantillon et le type de caractères

Fondements

Les éléments essentiels d'une étude statistique

Lorsqu'on réalise une étude statistique, il faut toujours déterminer trois éléments importants :

  1. 01 La population étudiée
  2. 02 L'échantillon choisi
  3. 03 Le caractère observé

Ces trois éléments permettent de comprendre précisément ce que l'étude cherche à mesurer.

Définition

La population

La population

La population est l'ensemble complet des personnes, objets ou événements que l'on souhaite étudier.

La population représente donc le groupe auquel on s'intéresse.

Exemple — Population d'une école

Une école secondaire veut connaître le temps moyen consacré aux devoirs par ses élèves.

La population est :

Tous les élèves de l'école

Même si tous les élèves ne répondent pas au questionnaire, c'est ce groupe complet qui intéresse l'étude.

Définition

L'échantillon

L'échantillon

Un échantillon est une partie de la population sélectionnée afin de recueillir des données.

Il est souvent impossible ou trop coûteux d'étudier toute une population. On utilise donc un groupe plus petit qui doit représenter le groupe complet.

Exemple — Sondage auprès des élèves

Une école possède 1200 élèves. La direction questionne 100 élèves choisis au hasard sur leurs habitudes de transport.

ÉlémentRéponse
PopulationLes 1200 élèves de l'école
ÉchantillonLes 100 élèves questionnés

Les 100 élèves représentent un échantillon de la population.

Définition

Le caractère étudié

Le caractère statistique

Le caractère statistique est l'information que l'on observe ou que l'on mesure chez les individus d'une population.

Pour trouver le caractère, on doit se demander :

Quelle information cherche-t-on à connaître ?
Exemple — Consommation d'électricité

Une compagnie veut connaître la consommation électrique des maisons d'une ville.

ÉlémentRéponse
PopulationToutes les maisons de la ville
Échantillon300 maisons sélectionnées
CaractèreLa consommation d'électricité en kWh
Types de caractères · 1 de 2

Le caractère qualitatif

Les caractères statistiques se divisent en deux grandes catégories : les caractères qualitatifs et les caractères quantitatifs.

Caractère qualitatif

Un caractère qualitatif décrit une qualité ou une catégorie. Les réponses sont généralement des mots.

Exemples de caractères qualitatifs :

Couleur préférée Marque de téléphone Moyen de transport Sport préféré Type de logement
Exemple — Sondage sur les téléphones

Une compagnie demande à ses clients : « Quelle marque de téléphone utilisez-vous ? »

Réponses possibles : Apple, Samsung, Google, Autre.

Le caractère étudié est :

La marque du téléphone

C'est un caractère qualitatif.

Types de caractères · 2 de 2

Le caractère quantitatif

Caractère quantitatif

Un caractère quantitatif représente une information numérique. Il peut être mesuré ou compté.

Exemples : l'âge d'une personne, le salaire annuel, le nombre d'enfants, la distance parcourue, le temps d'attente.

Les caractères quantitatifs se divisent en deux catégories.

Le caractère quantitatif discret

Quantitatif discret

Un caractère quantitatif discret correspond à une quantité que l'on peut compter. Les valeurs sont généralement des nombres entiers.

Exemples : nombre d'enfants dans une famille, nombre de voitures dans un stationnement, nombre de personnes dans une maison, nombre de visites chez le médecin.

Exemple — Une famille

Une famille répond : nombre d'enfants = 3. On peut compter les enfants.

Le caractère est donc :

Quantitatif discret

Le caractère quantitatif continu

Quantitatif continu

Un caractère quantitatif continu correspond à une mesure pouvant prendre plusieurs valeurs, incluant des nombres décimaux.

Exemples : la taille d'une personne, le poids d'un objet, la température, le temps nécessaire pour effectuer une tâche, la consommation d'essence.

Exemple — Consommation d'essence

Une voiture consomme 7,4 L/100 km. Cette valeur peut changer avec des décimales.

Le caractère est donc :

Quantitatif continu
Méthode

Identifier population, échantillon et caractère

Méthode
  1. Cherche le groupe complet étudié. → Population
  2. Cherche les individus réellement observés. → Échantillon
  3. Cherche l'information recueillie. → Caractère
  4. Détermine si le caractère est qualitatif ou quantitatif.

Résumé

À retenir

À retenir
  • La population est le groupe complet étudié.
  • L'échantillon est une partie de la population.
  • Le caractère est l'information recherchée.
  • Un caractère peut être qualitatif ou quantitatif.
  • Un caractère quantitatif peut être discret ou continu.
